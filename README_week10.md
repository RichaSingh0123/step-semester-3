- `Assignments/`: five standalone Java solutions for Part A coding problems.
- `Practice Problems/Week10_Quiz_Answers.md`: answers to the 20 Part B quiz questions.
- `Practice Problems/Week10_Concept_Answers.md`: short answers to the 10 Part C concept questions.

## Compile and run a program
Open Git Bash in the folder containing a Java source file, then run:

```bash
javac BankAccountWithdrawalMain.java
java BankAccountWithdrawalMain
```

Type the sample operations one per line, then signal end-of-input:
- Windows Git Bash: press `Ctrl+D` on a new line.
- Or redirect a text input file: `java BankAccountWithdrawalMain < input.txt`

Repeat using the relevant `.java` filename and class name for each problem.

## Important
Each Part A program is independent and reads operations/records from standard input until end-of-file. Use the sample input shown in the PDF to test it. The quiz and concept answers are included as Markdown files for quick revision.
